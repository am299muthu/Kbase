# AI tooling disclosure

## What was used

Claude Code's coding-assistant workflow was used to inspect the two source briefs and implementation, draft supporting documentation, author synthetic policy fixtures and 50 manual evaluation cases, and generate an editable architecture diagram plus PNG. This describes development assistance, **not the runtime model provider**. The application's requested external inference/embedding provider is OpenRouter.

Work was split by file ownership: backend/CLI/infrastructure, parsers, frontend, and documentation/evaluation assets. Documentation was grounded in `kb/config.py`, `db.py`, `agent.py`, `app.py`, `search.py`, `pipeline.py`, and the MCP/security/provider code. Diagram output is generated by the committed `scripts/render_architecture.py`, not by an opaque downloaded archive. No skill ZIP was extracted for diagram creation.

## Where assistance helped

- Converting broad banking aspirations into an implementation-versus-gap matrix.
- Keeping local extractive/lexical behavior distinct from OpenSearch/OpenRouter infrastructure paths.
- Designing access-boundary and action-safety questions alongside ordinary policy QA.
- Making synthetic data and unmeasured deployment/evaluation status explicit.

## Limitations and review responsibilities

AI-generated material can invent capabilities, overpromise refusal behavior, or mistake valid citation IDs for factual support. The docs therefore identify deterministic routing, missing general clarification logic, incomplete production controls. Human reviewers must inspect the final code, validate the manual rubric, run the app and review actual traces before submission. No model-quality improvement or productivity percentage was measured.

No API key was used for these documentation/evaluation assets. The exposed credential in the original requirement material was not copied and must be revoked/rotated by its owner. No real source corpus content was used to construct the synthetic evaluation set; actual source parsing was permission-blocked. No deployment, recording, external publication, full semantic-quality evaluation or independent security audit is claimed. Limited local smoke/latency measurements are separately documented in `evaluation/smoke-measurements.json`; they do not establish answer entailment.
